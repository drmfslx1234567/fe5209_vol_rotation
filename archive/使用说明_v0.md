# Pipeline 使用说明

## 在 PyCharm 中运行

1. 打开整个项目文件夹，选择 Python 3.10 或更高版本解释器。
2. 在该解释器对应的 Terminal 运行 `python -m pip install -r pipeline/requirements.txt`。
3. 打开 `pipeline/07_run_pipeline.ipynb`，选择同一个 Python 内核，点击 **Run All / 运行全部单元格**。
4. 结果会直接显示在 notebook 中，同时保存在 `results` 字典，例如 `results['baseline']['metrics']`。

不需要按编号先运行其他 notebook，也不需要手动调用各个小函数。如果 PyCharm 不提供 notebook 的内核或 Run All 功能，请确认已启用 Jupyter 支持。

```text
项目根目录/
├── data/etf_daily.csv
├── notebook/                 原始文件，保留
└── pipeline/
    ├── 00_engine.ipynb       公共函数定义
    ├── 01_baseline.ipynb     基线与买入持有
    ├── 02_is_grid.ipynb      样本内网格
    ├── 03_oos2020_walkforward.ipynb

    ├── 05_live_0915.ipynb

    ├── 07_run_pipeline.ipynb  推荐总入口

```

## 函数组织

总入口 `main()` → `prepare_context()` → `prep()` / `signals()` → `run_all()` → `run_stage()` → 各分析 notebook 的 `main()` → 该阶段的小函数。

每个分析 notebook 都有“加载公共函数 → 定义分析函数 → 定义 main → 调用 main”的结构。独立 Run All 时自行读取数据、完成计算；总入口调用时显式传入数据与网格结果，避免重复计算。加载其他 notebook 时跳过带 `pipeline-entry` 标签的入口单元格，不会连带运行其他报告。没有额外的本地 .py 模块依赖。

## 配置

总入口最后一格集中设置 `CSV_PATH`、`STAGES_TO_RUN`、`LIVE_START`、`LIVE_END`。默认自动寻找项目中的数据。PyCharm 工作目录设为项目根目录或 pipeline 目录；其他位置启动时，可设置环境变量 `ETF_PROJECT_ROOT` 指向项目根目录。`CSV_PATH` 或 `ETF_CSV` 可指定数据文件。

只跑某阶段可设置 `STAGES_TO_RUN = ['baseline', 'is_grid']`，也可直接打开对应 notebook Run All。更新数据使用 08 文件（需另外安装 yfinance），然后在总入口指定下载后的 CSV。

## 保留的研究口径

原策略决策树、Wilder RSI、均线、复权计算、36 组参数网格、邻域平均 Sharpe 选参、交易成本、T 日收盘信号 / T+1 开盘成交、止损止盈及阻止重复入场规则保持不变。基线分年收益、连续历史回测后切分 IS/OOS、Walk-forward 逐年收益拼接口径也沿用原代码。2024 OOS 仍保留“此前看过数据、并非完全盲测”的说明。

改变仅在流程组织、路径查找、显示并返回结果，以及空窗口保护。未来无数据的 Walk-forward 年份会跳过；实盘窗口无数据时返回 skipped。若数据未覆盖 LIVE_END，会标注未完成窗口，不补造未来数据。附带 CSV 截至 2026-10-07。

原始 notebook 和 CSV 不会被总入口修改。可选下载文件默认使用新文件名。
